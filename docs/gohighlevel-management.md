## 1. Automations

### 1.1 Monitor Existing Automations

**Trigger:** Ongoing GHL automation management.

1. Review current GHL automations.
2. Check automation execution records.
3. Identify failed, incomplete, or unexpected executions.
4. Investigate the cause of the error.
5. Fix the automation as needed.
6. Test the corrected automation.
7. Confirm that the automation is executing as intended.

### 1.2 Build New Automations

**Trigger:** A task inside GHL can be automated.

1. Identify the task or process that may benefit from automation.
2. Discuss the automation idea with Dimitrios.
3. Determine:
    - What the automation should accomplish.
    - What process the automation should serve.
    - What should trigger the automation.
    - What steps the automation should execute.
    - What conditions or decisions need to be included.
    - What the expected final result should be.
4. Finalize the automation workflow with Dimitrios.
5. Build the automation in GHL based on the finalized process.
6. Test-run the automation.
7. Verify that each step executes in the correct order.
8. Confirm that the automation produces the intended result.
9. Add fallback steps for situations where the automation fails or cannot complete an action.
10. Monitor the automation after activation and correct issues as needed.

### 1.3 Automation Requirements

Every automation should have:

- A defined **trigger**.
- A defined **sequence of actions**.
- **Conditions or decision points** where necessary.
- A defined **expected outcome**.
- A **fallback process** for failed execution.
- A **test run** before being activated.

## 2. Contact Management

### Monthly Email Marketing List Cleanup

**Trigger:** Monthly

1. Review the current GHL contact database.
2. Build/update the email marketing list.
3. Exclude contacts with hard-bounced emails.
4. Exclude contacts marked as DNC (Do Not Contact).
5. Verify the resulting list is suitable for email marketing.
6. Use the cleaned list for future email marketing campaigns.

**Purpose:** Maintain a cleaner email marketing audience and reduce delivery
issues during email campaigns.

!!! warning "Open Item"
    Define whether other exclusions should be applied, such as unsubscribed
    contacts, invalid email addresses, or other suppression lists.

## 3. Website Management

### 3.1 Universal Elements

1. Review website pages for elements that can be saved as universal elements.
2. Convert applicable repeated elements into universal elements.
3. Check similar elements across all pages.
4. Replace duplicate elements with the appropriate universal element where applicable.
5. Confirm that future changes to universal elements can be applied consistently across the site.

### 3.2 SEO and Metadata

Review all website pages and confirm they have:

- Meta tags
- Open Graph information
- SEO keywords

Update missing or incomplete metadata as needed.

### 3.3 Branding

1. Review website pages for branding consistency.
2. Use the established Lynch Team brand colors throughout the site.
3. Check similar elements across pages for consistent branding.
4. Correct inconsistent colors or styling where needed.

## 4. Page Building

**Trigger:** A new website page needs to be created or an existing page needs to be edited.

### 4.1 Planning

1. Coordinate with Dimitrios to determine:
    - Page purpose
    - Page content
    - Page layout
    - Required sections
    - Required CTAs
    - Intended audience
2. Confirm the page direction before building.

### 4.2 AI-Assisted Draft

1. Use AI to develop the initial page draft.
2. Generate or assist with visual concepts where needed.
3. Optimize page content for:
    - SEO
    - AEO
    - AI searchability
4. Review the generated content against the intended purpose of the page.
5. Make necessary revisions.
6. Present the draft for approval.

### 4.3 Build in GHL

!!! info "Only after the draft is approved"

1. Build the page inside the GHL Page Builder.
2. Add the approved content.
3. Add the approved layout and visual elements.
4. Add required CTAs and links.
5. Apply Lynch Team branding.

### 4.4 SEO and Metadata

Add:

- Meta tags
- Open Graph information
- SEO keywords

### 4.5 Review and Publish

1. Review the completed page with Dimitrios.
2. Apply requested revisions.
3. Recheck page content, layout, links, and metadata.
4. Once approved, publish the page.
5. Confirm the published page is functioning correctly.

## 5. Funnel Building

**Trigger:** A new funnel needs to be created or an existing funnel needs to be edited.

### 5.1 Planning

1. Coordinate with Dimitrios to determine:
    - Funnel purpose
    - Page content
    - Page layout
    - Target audience
    - Required CTAs
    - Lead capture requirements
    - Form/survey requirements
    - Lead workflow after form/survey submission
2. Determine how leads should enter and move through the funnel.
3. Confirm the funnel structure before building.

### 5.2 AI-Assisted Draft

1. Use AI to develop the initial page draft.
2. Generate or assist with visual concepts where needed.
3. Optimize page content for:
    - SEO
    - AEO
    - AI searchability
4. Review the generated content against the funnel's purpose.
5. Make necessary revisions.
6. Present the draft for approval.

### 5.3 Build Funnel Pages in GHL

!!! info "Only after the draft is approved"

1. Build the funnel page(s) inside the GHL Page Builder.
2. Add the approved content and layout.
3. Add required forms/surveys.
4. Add CTAs and required links.
5. Apply Lynch Team branding.
6. Add meta tags, Open Graph information, and SEO keywords.

### 5.4 Build Funnel Workflow

1. Create the workflow for leads entering through the funnel.
2. Define the trigger based on the form/survey submission or other agreed funnel entry point.
3. Build the workflow according to the process finalized with Dimitrios.
4. Configure the required actions, conditions, tags, notifications, or follow-up steps.
5. Add appropriate fallback steps for automation failures.
6. Test the workflow before activation.

!!! tip "Reference"
    Follow the **Automation Building** process in Section 1 when creating or
    modifying the funnel workflow.

### 5.5 Review and Publish

1. Review the completed funnel with Dimitrios.
2. Test:
    - Page functionality
    - Forms/surveys
    - Buttons and links
    - Lead submission
    - Workflow trigger
    - Workflow actions
    - Follow-up process
3. Apply requested revisions.
4. Once approved, publish the funnel.
5. Perform a final live test.
6. Confirm that submitted leads enter the correct workflow and that the funnel operates as intended.
