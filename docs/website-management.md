Standard Operating Procedure for maintaining The Lynch Team website.

---

## 1. Website Content Audit

- Review the website page-by-page to identify outdated, missing, or inconsistent information.
- Check key website sections and reusable elements for accuracy and consistency.
- Update outdated reviews, testimonials, and review placeholders.
- Replace or update video testimonials when new content is available.
- Update blog post listings to ensure the latest posts are displayed correctly.
- Review headers and footers for outdated links, information, or branding.
- Check website colors and visual elements to ensure they remain consistent with The Lynch Team branding.
- Fix or update any other outdated website content identified during the review.

---

## 2. SEO and Social Sharing

- Review each page's meta title and meta description and update them when needed.
- Check page metadata to ensure it accurately reflects the page content and target topic.
- Update Open Graph information used when pages are shared on social media.
- Create and add Open Graph images for pages that do not have an appropriate image.
- Check that page titles, descriptions, and images display correctly when shared.

---

## 3. Website Publishing and Quality Check

- Review all completed website changes before publishing.
- Verify that updated text, images, links, videos, and page elements are displaying correctly.
- Publish approved website updates.
- Review the live pages after publishing to confirm the changes went live correctly.
- Check for broken links, missing images, formatting issues, or other visible problems.
- Make corrections as needed and recheck the affected pages.

---

## Pre-Publish Checklist

Before publishing any website update:

- [ ] Content reviewed and approved
- [ ] Text, images, links, videos display correctly
- [ ] Meta title and description updated
- [ ] Open Graph image set
- [ ] Branding consistent
- [ ] No broken links
- [ ] No missing images

## Post-Publish Checklist

After publishing:

- [ ] Live page reviewed
- [ ] Changes visible as intended
- [ ] No formatting issues
- [ ] No broken links or missing images
- [ ] Corrections applied if needed
